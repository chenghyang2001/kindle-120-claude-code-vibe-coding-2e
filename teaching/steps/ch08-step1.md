## 2. 只輸入一句話

```
請幫我製作一個數獨遊戲app
```

觀察：選了什麼技術（網頁？Python 桌面？）、有沒有先問你問題。

## 3. 試玩後，貼上八項改良

```
幫我完成以下項目：
1.把難度分為4級(簡單、中等、困難、專家)，分級依據將參考人類解題時使用高級技巧(X-wing、swordfish...等等)的頻率以及挖空格數多寡。請先告訴我你認為的X-wing與swordfish是什麼。
2.加快題目產出的速度。
3.建立初始首頁。
4.新增返回上一步、暫停功能。
5.遊玩時自動存檔(實時紀錄解題時間)。
6.可自選背景風格。
7.新增遊玩紀錄、生涯總覽頁面。
8.新增每日挑戰，每天都有專屬題目。
```

重點：第 1 項要它**先解釋 X-wing 與 swordfish**（對齊術語），確認理解一致再動手。

提醒：全域規則會走 writer → QA；想快可回答「中等、不派 reviewer」。
