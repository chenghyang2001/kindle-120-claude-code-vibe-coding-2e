第一章到這裡全部完成。接下來是第二章，用一個 PDF 浮水印工具，走完整個開發流程。今天先做第一步，對應二之一節，寫 CLAUDE 點 md，並且設定編輯器。

開始之前有一個和書上不同的地方。書上把編輯器設成 VS Code，可是我檢查過，這台電腦沒有裝 VS Code，只有 Cursor。你可以二選一。第一，安裝 VS Code，指令是 winget install 空格 Microsoft 點 VisualStudioCode 空格 減減 scope 空格 user，裝在使用者層級，不需要系統管理員權限。第二，直接用 Cursor，等一下編輯器就填 cursor。

還有一個要注意的地方。書上把編輯器設定寫在使用者層級的 settings 點 json。但你這台的使用者設定，會同步到你的其他電腦，萬一那台沒有裝同一個編輯器，就會打不開。所以這次改寫在練習資料夾自己的 settings 點 local 點 json，只影響這個資料夾。這正好就是第一章提過的，不同範圍的設定檔。

請照著做。

第一，先決定要裝 VS Code，還是用 Cursor。要裝的話，先開新的終端機把它裝好。

第二，建立練習資料夾，名字叫 k 一二零 ch 零二 practice，放在 workspace 底下。進去之後，在裡面建一個點 claude 資料夾，在點 claude 資料夾裡面建立 settings 點 local 點 json。內容就是 env 裡面的 EDITOR 等於 code，或是 cursor。聊天視窗裡有完整的內容可以複製。

第三，在練習資料夾輸入 claude 啟動。設定檔是在啟動的時候讀進去的，所以要先建好檔案再啟動。

第四，輸入斜線 memory。看它列出了哪幾種記憶檔，選專案層級的那一個，也就是這個資料夾裡的 CLAUDE 點 md。這時應該會打開你設定的編輯器。

第五，把書上的三條 uv 規則貼進去，存檔，關掉編輯器。三條規則是：必要時使用 uv init 初始化資料夾，使用 uv add 加入套件，不要使用 pip，使用 uv run 執行 Python 腳本檔。

第六，回到 Claude Code，問它一句話：在這個資料夾要怎麼安裝 Python 套件？看它的回答有沒有照剛剛寫的規則。

做完之後，請直接把畫面貼過來，回報四件事。第一，你選了哪一個編輯器，斜線 memory 有沒有成功打開它。第二，memory 列出了哪幾種記憶檔。第三，Claude 怎麼回答安裝套件的問題。第四，資料夾裡多了哪些檔案。
