第一章，互動教學。先判讀第一步的結果，再說明第二步怎麼做。

第一步的四項結果，我又自己核對了一次設定檔，數值全部正確。安裝方式是原生安裝，版本是二點一點二八九，更新頻道是 latest，自動更新是關閉的。

有一個地方要提醒你。表格裡的依據欄寫的是設定檔和 version 指令，不是 doctor 畫面本身。這次比原本那台電腦好，因為它真的去讀了檔案，不是憑記憶回答。但它還是模型讀完之後轉述給你的。下次判斷現況時，請直接看工具自己的畫面，或者把畫面原文貼過來。

再來看和書上不一樣的地方，也就是自動更新。書上的原生安裝，預設是會自動更新的。原本那台電腦用 npm 安裝，自動更新也是開著的。這台新電腦卻是關閉的。原因是使用者資料夾裡的點 claude 點 json 設定檔，被寫入了自動更新等於 false。這個檔案每台電腦各有一份，不會跟著同步，所以應該是這台電腦之前有某個步驟把它關掉了。

關掉之後，影響的只是背景自動更新。你還是可以隨時輸入 claude 空格 update，手動更新。想打開的話，在 Claude Code 裡輸入斜線 config，找到 auto updates 那一項，切換成開啟就可以了。要不要打開由你決定。我建議打開，跟書上的情況一樣，後面的練習比較好對照。

接下來是第二步，對應書上的一之三節，牛刀小試。這一步不是寫程式，而是讓 Claude Code 幫你操作系統，安裝軟體套件管理工具 scoop。

請在練習資料夾的 Claude Code 裡照著做。

第一，貼上書上的提示詞。內容是：我要使用軟體套件管理程式，Windows 用 scoop，macOS 用 Homebrew，幫我安裝成僅限當前使用者使用。

第二，這一步要觀察三件事。一，它在執行前列出了哪些步驟。二，它請你允許哪些指令。按下允許之前，先看懂每一條指令在做什麼。三，它最後用什麼方法確認 scoop 已經裝好了。

第三，裝好之後，在同一個對話裡輸入驚嘆號，空一格，再輸入 scoop 空格 減減 version。驚嘆號開頭就是一之三節介紹的 shell 模式，指令會直接執行，不經過模型。

這裡你可能會遇到一個狀況：明明裝好了，卻顯示找不到 scoop 這個指令。這和我們剛才遇到的 ffmpeg 是同一個原因。安裝程式把路徑寫進了系統設定，可是已經在跑的 Claude Code 不會重新讀取。遇到的話，先不要急著修，把畫面記下來，再結束 Claude Code、重新啟動，然後再試一次。

做完之後，請回報四件事。第一，自動更新你決定要不要打開。第二，三個觀察點的結果。第三，scoop version 顯示的版本號碼，或是錯誤訊息。第四，PowerShell 七有沒有裝好。我會幫你判讀，再帶你進行第三步。
