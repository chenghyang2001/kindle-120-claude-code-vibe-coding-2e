互動教學，第五章。先判讀第一步，再進行第二步。

第一步做得非常好，只花了四十四秒。它打開網頁、讀 Console、看網路請求、截圖，接著回到程式碼裡找原因。找到的兩個錯誤，和舊電腦完全一樣。第一個是變數宣告時叫 graph，下一行卻用 graph Trend。第二個是更新圖表時傳進去的是空物件，而不是伺服器回傳的資料。

它還做了兩件舊電腦沒做的事。第一，它用 git diff 比對最近兩個 commit，發現這兩個錯誤都是最近才改出來的，commit 訊息寫著測試示範，所以它判斷可能是故意放進去的，就沒有自己動手修，而是先問你。第二，它從程式碼看出，點地圖的時候也會發生同樣的錯誤，但它也老實說，這一點只是讀程式碼推測，還沒有實際點過。

舊電腦還看到一個找不到檔案的錯誤，這次它沒有提到，那個錯誤本來就不影響功能。

接下來是第二步，對應五之三節，安裝 Playwright MCP，讓 Claude 自己開瀏覽器做自動化測試，再修好錯誤，最後把地圖上每個縣市都點一遍。

網站伺服器那個視窗請繼續開著。

第一，先結束 Claude Code。在練習資料夾的終端機輸入安裝指令。書上的寫法在 Windows 上要多加一層 cmd 斜線 c，因為 Windows 不能直接執行 npx。聊天視窗有完整指令。

第二，輸入 claude mcp get playwright，確認狀態是連線成功。不加範圍參數的話，這個 MCP 只會裝在這個專案，不會影響其他專案。

第三，啟動 claude，貼上第一句提示詞：請透過 playwright 開啟一二七點零點零點一冒號五千，並測試我的網頁應用程式功能是否正常。觀察它用的是 playwright 的工具，還是上一步的 Chrome 擴充功能。

第四，接著說：請幫我修正所發現的錯誤。

第五，再說：幫我依序點擊 SVG 地圖中全部的縣市，確認每個縣市的資料都正常。

這一步可能會遇到 MCP 回傳的內容太長，被截斷的提示。書上的解法是把 MAX 底線 MCP 底線 OUTPUT 底線 TOKENS 設成九萬。但是書上寫在全域設定，你的全域設定會同步到其他電腦，所以這次如果真的遇到，請改寫在這個專案的點 claude 斜線 settings 點 local 點 json，然後重開 Claude Code。

做完之後請回報四件事。第一，MCP 有沒有裝成功。第二，它用哪一個瀏覽器工具測試，找到了哪些問題。第三，修正之後圖表有沒有出現。第四，點完所有縣市，有沒有哪個縣市的資料有問題，有沒有遇到輸出被截斷。
