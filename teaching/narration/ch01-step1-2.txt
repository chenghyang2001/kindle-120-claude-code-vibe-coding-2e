第一章，互動教學。現在進行第一步的結果判讀，以及第二步的操作說明。

先講第一步的結果。你的 Claude Code 是用 npm 全域安裝的，版本二點一點二八九，已經是最新版，自動更新也是開啟的，頻道是 latest。這三項都沒有問題。

不過有一個值得注意的地方。你貼回來的結果，是另一個 Claude session 用它記得的資訊回答的，它其實沒有真的執行 doctor 指令。這次剛好答對，但這正是第一章想建立的觀念：要確認現況，就讓工具實際量測，不要只聽模型說。

另外，書上用的是原生安裝程式，你用的是 npm 安裝。兩者都能用。差別在於 npm 版的更新會經過 npm，如果 npm 擋掉安裝腳本，更新可能會靜默失敗。要不要改成原生版，由你決定。目前建議先不改，等真的遇到更新問題再處理。

接下來是第二步，對應書上的一之三節，牛刀小試。這一步不是寫程式，而是讓 Claude Code 幫你操作系統，安裝軟體套件管理工具 scoop。

請你另外開一個終端機，照著做。

第一，建立一個練習資料夾，名字叫 k 一二零 ch 零一 practice，放在 workspace 底下，然後進入這個資料夾，再輸入 claude 啟動。

第二，貼上書上的提示詞。內容是：我要使用軟體套件管理程式，Windows 用 scoop，macOS 用 Homebrew，幫我安裝成僅限當前使用者使用。

第三，這一步的重點是觀察三件事。一，它在執行前，列出了哪些步驟。二，它請你允許哪些指令，允許之前，先看懂每一條命令在做什麼。三，它最後用什麼方法確認 scoop 已經裝好了。

第四，裝好之後，在同一個對話裡輸入驚嘆號，空一格，再輸入 scoop 空格 減減 version。驚嘆號開頭就是一之三節介紹的 shell 模式，指令會直接執行，不經過模型。

做完之後，請回報三件事：你要不要改成原生安裝，三個觀察點的結果，還有 scoop version 顯示的版本號碼。我會幫你判讀，再帶你進行第三步。
