互動教學。先判讀第五章第三步，接著進入第六章。

第一，安裝。你要求裝在使用者層級，所以官方 Skill 被加上 global 參數，裝到你的全域 skills 資料夾。書上的指令預設是裝在專案裡。結果就是，連我這個教學對話也看得到它。這個資料夾還沒有被 git 追蹤，如果之後提交，就會同步到你的其他電腦。

第二，第一次用 playwright cli 測試，又找到四個新問題。例如選到沒有資料的縣市時，畫面還留著上一個縣市的金額；說明寫利率百分之二點二五，程式卻用一點七五；坪數填零或負數也照算。你要求修正，它就走了寫程式、驗證、審查三個 agent，再用 playwright cli 重測。這部分超出書上的範圍，但做得很紮實。

第三，自建的 Skill 有兩百二十四行、十一個步驟，disable model invocation 設成 true，允許的指令也只開放 playwright cli、curl 這幾個，範圍很小。你用斜線執行時，它照著步驟全部跑完都通過，還從截圖發現錯誤訊息被擠成一字一行。重點是，它遵守了 Skill 裡只做測試、不改程式的規定，先回報再問你要不要修。後來新增的縣市測試，是從地圖本身讀出縣市清單，不寫死，二十一個縣市一輪大約十六秒。

第四，斜線 context 的比較，結果和書上的印象不一樣。Skill 實際佔了九千九百。MCP 工具的定義有六萬一千八，但它們是延遲載入，用到才讀進來，沒有算進目前的用量。新版的 Claude Code 會延遲載入 MCP 工具，所以 MCP 佔 context 太多的問題，已經比書上寫的時候小很多。

另外，這個練習資料夾在本機累積了四個 commit，因為沒有權限，都推不上去。

第五章到這裡全部完成。

接下來是第六章，Hook，也就是在 Claude 使用工具的前後，自動執行你設定的規則。第一步對應六之二節的前半，測試三件事：PreToolUse 用退出代碼二能不能擋下修改，換成 PostToolUse 還擋不擋得住，以及退出代碼改成一會怎樣。

開始前有一個很重要的準備。你的全域設定本身就有很多 hook，會干擾實驗結果。舊電腦的做法是只讀專案的設定。所以這一章請用 claude 空格 減減 setting 減 sources 空格 project 逗號 local 來啟動。這樣全域的 hook 和權限設定都不會載入，但你的 CLAUDE 點 md 還是會讀。因為全域的自動模式也不會載入，它會一條一條問你權限，這是正常的。

請照著做。

第一，在 workspace 底下 clone 書上的 todo system 專案，資料夾名稱叫 k 一二零 ch 零六 practice。聊天視窗有完整指令。

第二，用剛剛說的參數啟動 claude，貼上書上建立 PreToolUse hook 的提示詞。

第三，hook 建好之後，結束再重新啟動，然後輸入：幫我把 tasks 點 json 第一個任務的狀態改成完成。觀察有沒有被擋下，以及 Claude 看到了什麼訊息。

第四，結束 Claude Code。因為 hook 現在會擋住所有修改，連 Claude 自己也改不了設定檔，所以請你用編輯器打開點 claude 斜線 settings 點 json，把 PreToolUse 改成 PostToolUse。重新啟動，輸入：幫我把 tasks 點 json 第二個任務的狀態改成未完成。

第五，再把設定檔改回 PreToolUse，並把 exit 二改成 exit 一。重新啟動，輸入：幫我把 tasks 點 json 第三個任務移除。

舊電腦的結果是：第一次被擋下，檔案沒變。第二次 PostToolUse 擋不住，因為工具已經執行完了，檔案被改了。第三次退出代碼一也擋不住，只有退出代碼二才會阻擋。

做完之後，請回報三次測試的結果，tasks 點 json 有沒有被改，以及 Claude 每次說了什麼。
