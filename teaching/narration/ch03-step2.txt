互動教學，第三章。先判讀第一步，再進行第二步。

第一步，記錄裡只留下斜線 context 的完整結果，斜線 usage 你開了三次都直接關掉了，斜線 cost、斜線 stats、斜線 diff 都沒有留下紀錄。所以我只能判讀斜線 context，其他的你可以之後再補看。

斜線 context 的結果很值得看。模型是 Opus 五點五，分母是一百萬個 tokens，用量是十八點三萬，也就是百分之十八。書上的 Sonnet 四點六，要另外開啟 usage credits 才有一百萬，預設是二十萬。你剛好也打了斜線 usage credits，畫面一度顯示登入成功，後來又中斷了。但不管有沒有開，這台的 Opus 五點五顯示的分母就是一百萬。

各項目裡，最大的是對話訊息，九萬兩千。第二大的是記憶檔，三萬五千一百，也就是你的全域 CLAUDE 點 md 和它引用的那些規則檔，每個對話一開始都要讀進去。再來是自訂 agent 一萬八千七，內建工具一萬八千四。

最有意思的是最後一行，自動壓縮的保留空間是三萬三千。書上的服務專區說明過，壓縮時要預留兩萬給摘要，再多留一萬三當緩衝，兩個加起來剛好就是三萬三千。書上的計算方法，在新版本裡還是成立的。

另外，延遲載入的 MCP 工具和系統工具，加起來大約七萬一千，但它們沒有算進百分之十八裡面，要用到的時候才會真的載入。

接下來是第二步，練習四個設定類的命令：斜線 model、斜線 config、斜線 permissions，還有斜線 statusline。

一樣請你自己輸入，不要把說明貼給 Claude。

第一，輸入斜線 model，看有哪些模型可以選，目前用的是哪一個。看完按 Esc 離開，不要切換。

第二，輸入斜線 config，瀏覽一下有哪些設定。找到第一章打開的自動更新，確認它是開著的。

第三，輸入斜線 permissions，看允許和拒絕的規則各有幾條。你的全域設定裡，預設模式是 auto，有三十六條允許、二十二條拒絕，看畫面上是不是一樣。

第四，自訂狀態列。你的全域設定裡已經有一個狀態列了，而且會同步到其他電腦。所以這次不要改全域的。請輸入斜線 statusline，後面接一句話：在狀態列顯示目前的資料夾名稱、git 分支，還有 context 用量百分比，只寫進這個專案的 settings 點 local 點 json，不要改全域設定。

第五，做好之後，看畫面最下面的狀態列有沒有變。然後用驚嘆號 cat 看一下點 claude 資料夾裡的 settings 點 local 點 json，確認設定寫在專案裡。

做完之後請把畫面貼過來，回報四件事。第一，有哪些模型可以選。第二，permissions 的允許和拒絕各有幾條。第三，狀態列變成什麼樣子。第四，設定寫到哪個檔案。
