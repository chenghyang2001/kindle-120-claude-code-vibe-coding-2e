互動教學，第八章。先判讀第一步，再進行第二步。

第一步，你只說了一句請幫我製作一個數獨遊戲 app，它沒有問任何問題，直接做了一個單一的 HTML 網頁，和書附範例一樣是純網頁。不同的是，它還把網頁發布成 claude 點 ai 上的 Artifact，給你一個只有你看得到的連結，可以直接在瀏覽器玩。這是新版的功能，書上沒有。第一版大約四分鐘完成。

八項改良的部分，它先完整解釋了 X wing 和 swordfish，解釋是正確的。X wing 是兩列裡，某個數字都只能放在同樣的兩行，所以那兩行其他位置的這個數字都可以刪掉。swordfish 是同樣的道理擴大成三列三行。

更好的是，它沒有馬上動手，而是先列出一張難度分級的規劃表：簡單只用最基本的技巧，中等要用到數對，困難要用到 X wing，專家要用到 swordfish，然後請你確認。你說確認之後，它才開始做。這就是書上說的對齊術語，先講好再做。

第二版大約九分半完成，八項都做到了：模擬人類解題的求解器、背景出題、首頁、上一步和暫停、自動存檔、四種背景、紀錄和生涯總覽、以日期當種子的每日挑戰。它在 Node 裡讓每個難度各出六題，全部只有唯一解，專家級最慢七百毫秒。

有三件事要注意。第一，這次完全沒有派寫程式和驗證的 agent，因為 HTML 不在你的全域規則清單裡，所以快很多。第二，它自己承認沒有在瀏覽器裡實際點擊試玩。第三，你沒有執行 git init，所以這個資料夾沒有版本控制。

接下來是第二步，對應八之三節，先寫 PRD 再開發。PRD 就是產品需求文件，把所有功能一次寫清楚，再讓 Claude 照著做。這次書上要求的是 Python 桌面程式。

我已經把書上的 CLAUDE 點 md 和兩個版本的 PRD 準備好了，放在 teaching 的 steps 資料夾裡，你直接複製過去就好。

請照著做。

第一，建立練習資料夾 k 一二零 ch 零八 practice 減 prd，把 CLAUDE 點 md 和 PRD 點 md 複製進去，再執行 git init，然後啟動 claude。聊天視窗和記事本有完整指令。

第二，只輸入一句話：完成小老鼠 PRD 點 md。

第三，做好之後，用 uv run python main 點 py 執行，實際玩一下。

第四，書上接著示範怎麼修正：把沒做好或要修改的地方，用雙星號標起來。我也準備好了這個版本，叫 PRD 減 v2 點 md。請用它取代原本的 PRD 點 md，然後輸入：我將需修正與未成功實作的內容用雙星號標示於小老鼠 PRD 點 md，請幫我修正。

這一步因為是 Python 檔，你的全域規則會讓它走寫程式、驗證、審查的流程，而且規模大，可能要很久。建議回答中等、不派審查。

舊電腦的評測結果是，PRD 版用 tkinter 做的，是四種方式裡出題最快、最穩定的，專家級平均不到半秒。

做完之後請回報四件事。第一，它選了哪個 GUI 套件。第二，花了多久。第三，玩起來功能有沒有都做到。第四，雙星號修正之後，改了哪些地方。
