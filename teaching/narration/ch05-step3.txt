互動教學，第五章。先判讀第二步，再進行第五章最後一步。

第二步你把三句提示詞一次貼進去，它也一次全部做完，總共不到七分鐘。

它用的確實是 Playwright 的工具，不是 Chrome 擴充功能，所以 MCP 有裝成功。而且這次沒有寫進專案的點 mcp 點 json，是存在你這台電腦這個專案的本機設定裡。

找到的問題比舊電腦和上一步都多。除了原本那兩個圖表錯誤，它還找出投資報酬率少除了一百、拖拉滑桿時事件重複綁定，送出很多次請求、錯誤訊息會一直往下疊，還有那個找不到檔案的錯誤。網頁的 html 它直接改，兩個 js 檔改動超過三行，所以先問你複雜度，再派寫程式和驗證的 agent。

點縣市的方式也和書上想的不一樣。它不是一個一個點、每點一次就回傳一大堆畫面內容，而是寫一小段程式，讓 Playwright 一次把二十一個縣市點完，只回傳整理好的結果。所以完全沒有遇到輸出被截斷的問題，也就用不到調整 token 上限的設定。二十一個縣市全部正常，只有金門的租金顯示資料不足，連江縣本來就沒有資料。

有兩件事要特別提醒。

第一，它 commit 完之後，還試著推到 GitHub，結果被拒絕了。因為這個專案是從出版社的 repo 抓下來的，你沒有寫入權限。它會這樣做，是因為你的全域設定寫著 commit 之後一律直接 push。這次剛好沒有權限所以沒事，但如果是你有權限的別人的專案，就會直接推上去了。

第二，那個對話的回覆整個變成英文了，你全域設定的語言規則在那裡沒有生效。如果之後又發生，可以直接告訴它用繁體中文回答。

接下來是第三步，對應五之四節，改用 Playwright CLI 加上 Skill，把測試流程打包起來，再比較 MCP 和 Skill 各佔用多少 context。

第一，在終端機用 npm 全域安裝 Playwright CLI，再下載瀏覽器，然後把官方 Skill 裝進 Claude Code。三行指令都在聊天視窗。

第二，啟動 claude，先輸入斜線 playwright 減 cli 載入官方 Skill，再請它開啟臺灣房價地圖首頁，對網站的主要功能做測試。

第三，請它把剛剛的測試流程，建立成一個叫 playwright 減 test 的 Skill，放在專案的點 claude 斜線 skills 裡，而且 disable model invocation 要設成 true。聊天視窗有書上的完整提示詞。

第四，結束再重新啟動 claude，輸入斜線 playwright 減 test，看它會不會照著流程測試。

第五，請它在這個 Skill 裡新增一個測試項目：依序點擊地圖上所有縣市，確認每次點擊後數值都會更新。

第六，輸入斜線 context，看 MCP 工具佔了多少，Skill 又佔了多少。

disable model invocation 的意思是，這個 Skill 只能由你用斜線命令叫出來，模型不會自己決定去用它。

做完之後請回報四件事。第一，三行安裝指令有沒有成功，官方 Skill 裝到哪裡。第二，自建的 Skill 檔案內容大概有哪些步驟。第三，用斜線執行時有沒有照流程跑。第四，斜線 context 裡 MCP 和 Skill 各佔多少。
