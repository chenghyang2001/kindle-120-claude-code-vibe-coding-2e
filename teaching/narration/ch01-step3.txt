第一章，互動教學。你沒有回報第二步的結果，所以我直接讀了練習資料夾的對話記錄，也實際檢查了電腦的狀態。先判讀，再進行第三步。

第二步的結果。scoop 已經裝好了，版本是零點六點零，裝在使用者資料夾底下的 scoop 資料夾，路徑也已經寫進使用者的設定。自動更新已經打開，PowerShell 七也裝好了，版本是七點六點六。

不過這次的過程和書上有三個不一樣的地方。

第一，你沒有貼書上的提示詞，而是先輸入驚嘆號 scoop version，結果顯示找不到指令。接著 Claude 回答，依照你的全域設定，這台電腦優先用 winget，平常不需要 scoop。這句話不是來自書，而是來自你自己的全域 CLAUDE 點 md。這正好示範了一件事：同一個問題，在不同人的電腦上，會因為設定檔不同而得到不同的回答。

第二，三個觀察點。它執行前先確認自己不是系統管理員，因為 scoop 的安裝程式不允許用系統管理員權限執行。接著把 PowerShell 的執行原則設成只限目前使用者，最後執行官方的安裝指令。允許指令的部分，你這台預設是 auto 模式，所以它沒有一條一條問你，這點和書上的畫面不同。書上預設會先問過你，才執行指令。驗證的方法是執行 scoop version，但它先手動把 scoop 的路徑加進去才執行。原因就是我上一步提醒你的：正在執行的程式不會重新讀取路徑設定。

第三，也是最重要的一點，doctor 指令本身。書上的 doctor 是一個固定的診斷畫面。你這個版本的 doctor 卻是讓模型自己跑一連串指令來做健康檢查，所以上一步表格的依據才會是設定檔。我上一步說「這不是 doctor 畫面」，這句要更正：在這個版本裡，模型去讀這些檔案，就是 doctor 本身的做法。而且它不只檢查，還提出清理建議。你同意之後，它改了你的全域設定，停用了九個 plugin，也縮短了八十多個 skill 的說明。這些改動都已經同步到你的其他電腦。這提醒我們：在同意之前，要先看清楚它打算改哪些東西。

接下來是第三步，對應書上的一之三節，接續對話和記憶。

第一，先把目前的 Claude Code 結束，輸入斜線 exit。然後把這個終端機視窗也關掉，重新開一個新的。這一點很重要，因為舊的視窗不知道 scoop 的路徑，在舊視窗裡重新啟動 Claude Code 也沒有用。

第二，在新視窗裡進入練習資料夾，輸入 claude 空格 減 c。減 c 會直接接續這個資料夾最近的一次對話。請看它有沒有接回剛才安裝 scoop 的那段對話。接著輸入驚嘆號 scoop 空格 減減 version，這次應該就能看到版本號碼了。

第三，再輸入斜線 exit 離開，這次改輸入 claude 空格 減減 resume。它會列出這個資料夾的對話清單，讓你自己選要接續哪一個。請注意看清單裡有幾個對話，有沒有不是你自己開的。

第四，隨便選一個進去之後，輸入斜線 memory。看它列出了哪幾種記憶檔，各自放在哪裡。

做完之後請回報四件事。第一，減 c 接回的是哪一段對話。第二，scoop version 這次有沒有成功。第三，resume 清單裡有幾個對話，有沒有你不認得的。第四，memory 列出了哪些檔案。
