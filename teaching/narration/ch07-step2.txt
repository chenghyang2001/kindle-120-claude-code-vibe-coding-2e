互動教學，第七章。先判讀第一步，再進行第二步。

從你貼的截圖看，桌面版和終端機最大的不同有三個。第一，左邊是對話清單，按專案分組，同一台電腦的所有專案和對話都看得到。第二，中間是對話，最下面可以直接切換模式、模型和思考程度，還有麥克風可以用語音輸入。第三，右邊就是 Preview，它是一個內建的瀏覽器分頁，有網址列，可以直接在裡面操作網頁。

Preview 有自動打開，網頁顯示旗標訂餐系統，橘色的分析菜單按鈕，分析完成共六個品項，下面有品項卡片、客製化選項、數量和備註，最下面固定一列姓名欄和送出訂單按鈕，合計會即時計算。你把雞腿便當數量改成二，合計就變成三百元，算得正確。

按分析菜單會發生什麼事，它也說明得很清楚。因為瀏覽器有跨網域限制，純前端沒辦法直接去抓別人網站的菜單，所以現在不管貼什麼網址，都會等一點五秒，然後顯示同一份範例菜單。送出訂單也只是跳出摘要，沒有真的送到任何地方。這些都要等後端完成才會變成真的。它還特別標註，之後只要改 analyze Menu 這個函式就能接上後端。

它做完在 master 分支 commit 了，因為這個 repo 沒有遠端，所以沒有 push。總共花了一分三十七秒，用了三千五百個 token。

接下來是第二步，對應七之二節，Remote Control。意思是讓 Claude Code 繼續在你的電腦上執行，你人不在電腦前面，也可以用手機遙控它。這一步要用手機下指令，請它寫後端。

請照著做。

第一，在終端機進入練習資料夾，輸入 claude 啟動。

第二，輸入斜線 remote 減 control。畫面會出現一個網址或 QR code。

第三，用手機打開 Claude App，或是掃描 QR code，找到這個對話。

第四，在手機上貼上書上的提示詞，請它用 Flask 建立後端 app 點 py，分析菜單的 API 先回傳假資料，送出訂單的 API 寫入 orders 點 xlsx，並允許跨網域。聊天視窗有完整提示詞，你可以先把它傳到手機上。

第五，觀察電腦這邊的終端機，會不會同步顯示手機下的指令和 Claude 的回應。如果它要你允許權限，看看手機上能不能直接按允許。

第六，完成後，照它說的方法啟動後端。先確認五千連接埠沒有被占用，我檢查過目前是空的。

還有另一種方式，是用 claude 空格 remote 減 control 直接啟動，這是伺服器模式，不會進入對話畫面，專門給遠端連線用。有興趣可以比較兩種的差別。

做完之後請回報三件事。第一，手機怎麼連上的，畫面長什麼樣子。第二，手機下的指令，電腦這邊有沒有同步顯示。第三，後端用什麼指令啟動，有沒有成功。
