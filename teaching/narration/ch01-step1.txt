第一章，互動教學，在新電腦上重做第一步。

先報告環境檢查的結果。git、node、VLC 都已經有了。Claude Code 裝在使用者資料夾底下的 local bin 裡面，看起來是原生安裝，不過這只是我從檔案位置推測的，等一下要請你用工具實際確認。

原本缺的 ffmpeg、uv、edge tts 三樣，我已經幫你裝好了。裝好之後還踩到一個坑：新裝的 ffmpeg 是第九版，它把字幕工具用到的一個舊參數拿掉了，所以影片做不出來。我已經把工具改成新的寫法，現在可以正常產生影片了。

還有一樣要請你自己裝，就是 PowerShell 七。安裝時會跳出系統管理員的確認視窗，所以要由你來按。書上一之二節第一個步驟就是安裝它。

另外，Python 這台是三點一四版，交接文件寫的是三點一二版。前面幾章不受影響，到第九章再處理。

接下來是第一步，對應書上的一之二節。這次一定要讓工具實際量測，不要聽模型憑印象回答。

請你另外開一個新的終端機，照著做。一定要開新的，這樣剛剛裝好的 ffmpeg 和 uv 才會生效。

第一，先安裝 PowerShell 七。輸入 winget install 空格 減減 id 空格 Microsoft 點 PowerShell 空格 減 e，跳出確認視窗時按是。

第二，建立練習資料夾，名字叫 k 一二零 ch 零一 practice，放在 workspace 底下，然後進入這個資料夾，輸入 claude 啟動。

第三，在 Claude Code 裡輸入斜線 doctor。注意，是醫生的 doctor，不是貨櫃的 docker。

第四，在 doctor 的畫面裡，找出三件事。一，安裝方式，是原生安裝，還是 npm。二，目前的版本號碼。三，自動更新是開啟還是關閉，以及更新頻道是哪一個。

做完之後，請把這三項結果回報給我。最好直接把 doctor 畫面的文字貼過來，我會幫你判讀，再和原本那台電腦的結果做比較。
