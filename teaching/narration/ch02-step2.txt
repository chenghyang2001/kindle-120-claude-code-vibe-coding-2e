互動教學，第二章。先判讀第一步，再進行第二步。

第一步的結果，我從對話記錄和資料夾的檔案讀到的。你選了 Cursor，斜線 memory 成功用 Cursor 打開了這個資料夾的 CLAUDE 點 md，畫面上也寫著正在使用 EDITOR 等於 cursor，所以設定檔有生效。

你問怎麼安裝套件，Claude 回答要先 uv init，再用 uv add，執行用 uv run，還特別說不要用 pip。這就是照著 CLAUDE 點 md 的規則回答的。不過有一個細節值得注意。CLAUDE 點 md 是在這個對話開始之後才建立的，它在回答之前，還是先用指令把檔案讀了一次。所以這次照規則回答，有可能是因為它自己去讀了檔案，不一定是自動載入的效果。要確認 CLAUDE 點 md 會在啟動時自動讀進去，最準的方法是開一個新的對話，什麼都不說，直接問同一個問題。

資料夾裡的檔案有三個。CLAUDE 點 md 和 settings 點 local 點 json 是你建的。另外還多了一個 session state 點 md，那是你全域設定裡的 hook 產生的，書上不會有。還有一個小地方：CLAUDE 點 md 每一行前面都多了兩個空白，應該是從聊天視窗複製時一起帶進來的。兩個空白不影響。但如果變成四個空白，Markdown 就會把它當成程式碼區塊，規則的效果可能會變差。

memory 列出了哪幾種記憶檔，記錄檔裡沒有留下，這一題就先跳過。

接下來是第二步，對應二之二節，讓 Claude 開發 PDF 浮水印工具。

開始前有一個很重要的提醒。你的全域設定裡有一個 hook，規定模型不能直接寫 Python 檔，必須先派寫程式的 agent，再派驗證的 agent。所以等一下，練習資料夾的 Claude 很可能會先問你這次的複雜度，還有要不要派審查的 agent。這不是書上的流程，是你自己的規則。你可以照它的預設回答，但請把這段過程記下來，等一下和書上的結果比較。

請照著做。

第一，在練習資料夾的 Claude Code 裡，貼上書上的初始提示詞。聊天視窗有完整內容可以複製。

第二，這一步要觀察四件事。一，它有沒有自己產生一份測試用的 PDF，而且裡面有不同尺寸的頁面。二，它有沒有照 CLAUDE 點 md 用 uv，而不是用 pip。三，最後有沒有幫你打開加了浮水印的 PDF。四，它用了哪些 agent，花了多久。

第三，PDF 打開之後，請自己檢查每一頁都有 Confidential 字樣，而且大小頁面的位置都正常。

舊電腦跑書附範例的時候，測試 PDF 有三頁，分別是 A4、Letter 和 A3，三頁都有浮水印。你可以拿來對照。

做完之後請回報四件事。第一，產生了哪些檔案。第二，測試 PDF 有幾頁、各是什麼尺寸。第三，浮水印看起來正不正常。第四，hook 有沒有介入，它問了你什麼。
