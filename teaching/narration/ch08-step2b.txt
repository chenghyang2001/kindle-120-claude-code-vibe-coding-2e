互動教學，第八章第二步的中場判讀。這一步還沒完全做完，練習資料夾那邊的寫程式 agent，現在還在修你剛剛要求的小問題，所以我先判讀前半段。

第一，技術選擇。它開工前先問你要用哪個 GUI 套件，推薦 PySide6，你也選了它。舊電腦的書附範例用的是 tkinter。它也先寫了一份規格書放在 docs 資料夾，這是你全域規則要求的規格先行，書上沒有這一步。

第二，花的時間。從輸入完成小老鼠 PRD 點 md，到 commit，大約四十分鐘。做出二十四個檔案，加上測試總共三千三百多行，測試從七十七個增加到一百二十一個。

第三，審查抓到一個很關鍵的問題：第一版的中等難度，其實幾乎都是簡單題，四十題裡只有五題真的是中等，每日挑戰甚至每天都是簡單題，畫面卻標示中等。修正之後，四種難度各出二十題全部符合，每日挑戰十月到十二月共九十二天也都符合中等。

第四，它自己誠實承認一個和 PRD 精神不符的地方：專家難度現在只靠進階技巧也解不開來判定，沒有任何一題是因為需要用到 X wing 才被分成專家。這正好就是書上雙星號版 PRD 要強調修正的地方：分級依據要參考使用高級技巧的頻率。所以等一下的雙星號修正，請特別看它有沒有改善這一點。

第五，它只在沒有視窗的環境截圖檢查畫面，按鈕上的圖示顯示成方框，它建議你實際開一次視窗確認。

接下來請這樣做。

先等練習資料夾那邊的 agent 把小問題修完、commit 並 push。不要在它還在改檔案的時候換 PRD，不然兩邊會同時改到同一批檔案。

完成後，先執行 uv run python main 點 py，自己開視窗玩一下，看圖示是不是正常。

然後照上一則訊息的第四到第六步：用 PRD 減 v2 取代 PRD 點 md，再請它依照雙星號修正。

做完之後說 proceed next，我會判讀雙星號修正的結果。
